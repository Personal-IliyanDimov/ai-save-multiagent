# SAFe context library

Local, paraphrased reference material for the agents. Read this before going to the web.

| File | Use it for |
|---|---|
| `big-picture.md` | Configurations, levels, how the roles fit together |
| `roles/*.md` | One card per role (mission, responsibilities, decision rights) |
| `events.md` | PI Planning agenda, ART Sync, System Demo, I&A, team events |
| `artifacts.md` | Backlogs, work item hierarchy, boards, metrics |
| `principles.md` | Core values, the ten Lean-Agile principles, how to apply them as an agent |
| `glossary.md` | Short definitions of the terms agents use most |
| `templates.md` | Markdown formats for epics, features, stories, PI objectives, ROAM, WSJF |
| `sources.md` | Official pages on framework.scaledagile.com for deeper reading |

All text here is a simplified paraphrase for simulation. SAFe® is a registered trademark of
Scaled Agile, Inc.; the official framework site is the authoritative source.
